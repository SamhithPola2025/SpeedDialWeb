SpeedDial

Welcome to SpeedDial, your end to end encrypted calling application (only works locally for now.)

Click here to download!: Download V1

Any complaints/issues can go in the GitHub repository for the main project: GitHub

Installation:

1: Unzip the folder once downloaded

2: Navigate to the dist folder

3: Open the file named "run" (the binary python executable)

Note that this app only works on linux/mac based systems,
and more support will be coming soon, and it only works locally for the time being,
all of this will be fixed in V2 coming out shortly!
